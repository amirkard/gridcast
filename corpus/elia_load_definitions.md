# Elia: definitions of grid load and load forecasts

Source: Elia, "Load and load forecasts", https://elia.be/grid-data/load-and-load-forecasts
(quoted from the web page, October 2026).

## Elia grid load

The "Elia Grid Load" is the share of the total electricity consumption supplied
via the Elia grid (including grid losses).

## Total load

The "Total Load" is an estimation of the total electricity consumption in
Belgium (including grid losses).
